# Juguetería Mundo Feliz

Sitio web de una juguetería con catálogo y formulario de contacto. Solo frontend, hecho con HTML, CSS y JavaScript.

Lo hice para la asignatura Desarrollo Full Stack II (Duoc UC).

## Qué tiene

- Página de inicio con bienvenida y catálogo de seis productos.
- Tarjetas que se marcan como favoritas al hacer clic, con un contador.
- Formulario de contacto con validación: campos obligatorios y nombre solo con letras.
- Año del pie de página actualizado automáticamente.

## Estructura

```text
jugueteria/
├── index.html
├── contacto.html
├── css/style.css
├── js/script.js        Favoritos, contador y validación del contacto
├── js/validaform.js    Validación del nombre (solo letras)
└── img/
```

## Tecnologías

HTML5, CSS3 y JavaScript.

## Cómo verlo

No necesita instalación. Clona el repositorio y abre `jugueteria/index.html` en el navegador.

```bash
git clone https://github.com/CristobalViveros/Jugueteria_Mundo_Feliz.git
```

## Nota

Proyecto con fines educativos. No tiene servidor ni base de datos: los formularios solo se validan en el navegador.
